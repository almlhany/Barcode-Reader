# Barcode Reader — Flutter Template

قالب تطبيق قارئ باركود وQR احترافي مع سجل محلي، تم تحديث بنية البناء والإصدارات فيه لتطابق القالب المرجعي الحديث مع الحفاظ على كود قارئ الباركود وتبعياته.

## إصدارات البناء
- Flutter: `3.47.2` افتراضيًا في Workflow.
- Java: `17`.
- Gradle Wrapper: `8.14`.
- Android Gradle Plugin: `8.11.1`.
- Kotlin: `2.2.20`.
- compileSdk وtargetSdk: `36`.
- minSdk: `21`.

## التبعيات
- `mobile_scanner: ^3.5.7`
- `shared_preferences: ^2.2.2`
- `url_launcher: ^6.2.4`

## التشغيل
استورد المجلد كاملًا داخل FlutterIDE، مع إبقاء `pubspec.yaml` و`android/` في الجذر، ثم شغّل Build APK.
